## 어려웠던 점 3가지와 해결
- 어려웠던 점:컴퓨터 환경에서는 상세 페이지 배경 이미지가 정상적으로 출력되었으나, GitHub Pages 배포 후 웹상에서는 배경 이미지가 나타나지 않는 문제가 발생했습니다.
- 해결 방법: GitHub 서버가 대소문자를 엄격하게 구분한다는 점을 확인하고, CSS 파일 내 이미지 URL 및 파일 경로의 대소문자를 정확히 맞추었습니다. 또한 문제를 점검(Ctrl + F5 강력 새로고침)하여 정상적으로 출력되도록 해결했습니다.
- 어려웠던 점: 상세 페이지의 포스터와 상세 정보가 핸드폰 화면에서는 세로로 정렬되고, 컴퓨터 화면에서는 가로로 나란히 2단 배치되도록 화면 크기별 구조를 잡는 것이 헷갈렸습니다.
- 해결 방법: `display: grid`와 미디어 쿼리(`@media`)를 사용하여, 화면이 넓어지면 자동으로 2단 구조로 바뀌도록 코드를 작성해 모바일과 PC 모두에서 깔끔하게 보이도록 해결했습니다.
- 어려웠던 점:CSS에서 글자 스타일(크기, 색상 등)을 바꾸려고 코드를 고쳤는데, 웹페이지를 열어봐도 글씨가 전혀 안 변하고 그대로인 경우가 있었습니다.
-해결 방법:*코드를 잘못 적은 게 아니라, 선택자 이름이 미세하게 달랐거나 상위 스타일의 영향(우선순위) 때문에 적용이 안 된 것을 확인했습니다. CSS 선택자 명칭을 정확히 일치시키고 스타일 코드를 다시 올바르게 수정하여 글씨가 정상적으로 바뀌도록 해결했습니다.
